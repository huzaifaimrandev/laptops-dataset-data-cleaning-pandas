# laptops-dataset-data-cleaning-pandas
A data cleaning project focused on preparing a laptop specifications dataset for analysis and modeling. Demonstrates data wrangling, missing value handling, feature standardization, and preprocessing using Python and Pandas.
## 📊 Project Overview

In this project, I worked with a dataset containing information about various laptop specifications — including brand, processor, RAM, storage, GPU, and price.  
The goal was to **clean, structure, and standardize** the data to make it analysis-ready.

### Key objectives:
- Handle **missing and inconsistent values**  
- Remove **duplicates and irrelevant features**  
- Parse and **standardize column formats** (e.g., storage, RAM, prices)  
- Perform **data type conversions**  
- Create **derived columns** for better insights  
- Export the cleaned dataset for further use
